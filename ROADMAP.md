# ROADMAP.md

# Проект «Мой день»

## Цель проекта

«Мой день» --- приложение, которое помогает не только организовать день,
но и создать хорошее настроение с самого утра.

Главная идея --- открыть приложение и за несколько минут увидеть всё
самое важное на сегодня:

-   погоду;
-   задачи;
-   праздники;
-   историческое событие;
-   дни рождения;
-   события дня;
-   тихую мысль дня;
-   улыбку дня.

Приложение должно быть полезным, уютным и таким, чтобы к нему хотелось
возвращаться каждый день.

------------------------------------------------------------------------

# Главный принцип разработки

Сначала --- архитектура.

Потом --- данные.

И только потом --- визуальная атмосфера.

Мы не строим красивые экраны поверх хаоса.

Мы создаём надёжные модули, которые можно развивать независимо друг от
друга.

------------------------------------------------------------------------

# Архитектура проекта

Проект состоит из независимых модулей.

## ✅ Calendar Core

Календарь.

-   государственные праздники;
-   православные праздники;
-   личные события;
-   диапазоны дат;
-   точки на календаре;
-   описания.

## ✅ History Core

Историческая справка. **Завершён.**

База: 366/366 дат, на каждой есть verified WORLD. RU — дополнительный редакционный слой; RU не требуется на каждой дате. Помесячные RU-аудиты выполнены и не являются условием готовности модуля.

Сортировка главного: `editorialRank → interest → priority → year`.

Каждое событие содержит:

-   дату;
-   год;
-   название;
-   краткое описание;
-   полный текст;
-   категорию;
-   приоритет;
-   статус проверки;
-   источник.

Показываются только проверенные события.

Отсутствующие изображения у части главных событий — **backlog**, не блокер готовности модуля (`assets/history/`).

## ✅ Weather Core

Погода.

-   текущая погода;
-   прогноз на 5 дней;
-   красивые погодные сцены.

Завершено: mock заменён на Open-Meteo, работают текущая погода и прогноз на 5 дней. Местоположение берётся только из профиля; geo и ручной ввод пока не реализованы и остаются будущим расширением.

## ✅ Tasks Core

Задачи.

-   список дел;
-   выполнение;
-   локальное хранение.

## ✅ Holidays Core

Праздники.

-   государственные;
-   международные;
-   необычные.

## ✅ Birthdays Core

Дни рождения.

-   поздравления;
-   напоминания.

## ✅ Quotes Core

Тихая мысль дня.

Работает через `js/gentle-thought.js` и `assets/data/wisdom.json`.

## ✅ Smile Core

Улыбка дня.

Добрая короткая шутка или интересный факт.

------------------------------------------------------------------------

# Историческая база

Необязательный backlog качества данных, изображений и RU. Это не развитие History Core.

Каждое событие должно иметь:

-   проверенную информацию;
-   ссылку на источник;
-   статус проверки.

Главная цель --- качество, а не количество.

------------------------------------------------------------------------

# Атмосфера приложения

После завершения MVP начинается следующий этап.

Главная задача --- сделать приложение живым.

Планируется:

-   погодные сцены;
-   сезонные оформления;
-   мягкие анимации;
-   единый стиль исторических иллюстраций;
-   несколько тем оформления;
-   плавная смена атмосферы.

Все эффекты должны быть лёгкими, спокойными и не отвлекать от
информации.

------------------------------------------------------------------------

# Исторические иллюстрации

Не использовать случайные изображения из интернета.

Использовать собственную библиотеку авторских иллюстраций.

Стиль:

-   современная редакционная иллюстрация;
-   единая художественная стилистика;
-   мягкие цвета;
-   премиальное оформление;
-   WebP;
-   единый размер.

Иллюстрация должна передавать смысл события, а не быть фотографией.

------------------------------------------------------------------------

# Темы оформления

В будущем пользователь сможет выбрать оформление приложения.

Например:

-   Летнее утро
-   Осенний парк
-   Зимний день
-   Весеннее цветение
-   Морской берег
-   Горное утро
-   Космос
-   Минимализм

Также будет доступен автоматический режим, когда оформление меняется в
зависимости от сезона и погоды.

------------------------------------------------------------------------

# Будущее развитие

-   Ежегодное обновление историй: возможность показывать для одной даты разные события в разные годы. Рассматривать только после завершения первого полного года в модели “одно событие в день”; требует отдельного архитектурного аудита и решения.

------------------------------------------------------------------------

# Главная цель

Мы создаём не просто ежедневник.

Мы создаём приложение, которое хочется открыть утром.

Оно должно быть:

-   полезным;
-   красивым;
-   живым;
-   уютным;
-   современным;
-   надёжным.

Каждый новый модуль должен отвечать на вопрос:

"Сделает ли он начало дня немного лучше?"

Если ответ «да» --- значит мы движемся в правильном направлении.
