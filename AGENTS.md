# Agent Workflow

Этот файл задаёт только workflow ролей. Содержательные правила разработки, проверки и коммитов остаются в Standards и в workspace instructions.

## Roles

- architect: формирует план и критерии приёмки, без изменений файлов.
- executor: реализует только утверждённый план.
- reviewer: независимо проверяет результат против цели и критериев.

## Mandatory sequence

1. Architect
2. Executor
3. Reviewer
4. При FAIL от reviewer: вернуть замечания в executor
5. Повторять шаги 2-4 до PASS или до лимита

## Loop limit

- Максимум 3 цикла executor-reviewer.
- После 3 FAIL: остановиться и отдать пользователю нерешённые блокеры.

## Fallback mode

- Если отдельные агенты недоступны, выполнить те же роли последовательно в одной сессии:
  - сначала секция Architect,
  - затем секция Executor,
  - затем секция Reviewer,
  - с тем же лимитом в 3 цикла.

## Scope

- Не дублировать Standards и прочие policy-файлы.
- Использовать этот файл только для порядка orchestration.
