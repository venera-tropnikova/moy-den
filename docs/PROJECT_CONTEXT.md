# PROJECT_CONTEXT.md

## Название и тип продукта

**Мой день** — клиентское PWA-приложение (`manifest.json`, `display: standalone`).  
Стек: HTML / CSS / JavaScript без фреймворка.

## Главная идея

Спокойное утреннее приложение. Главный вопрос: **что меня ждёт сегодня?**  
Не ежедневник и не корпоративный планировщик.

## Для кого продукт

Для личного ежедневного открытия утром: понять день, а не сразу уйти в список дел.

## Что приложение делает

Сейчас на главной (`index.html`):

- приветствие и дата;
- погода (карточка с текущей погодой + прогноз на 5 дней; данные — Open-Meteo через `js/weather.js`);
- праздники и даты (JSON календаря + важные даты из `localStorage`);
- историческая справка (локальный JSON, интерактивная карточка; полное покрытие дат года — 366/366 verified WORLD как база; изображения уже используются у части событий);
- поздравления (дни рождения / empty-state);
- анекдот дня;
- план на сегодня (задачи в `localStorage`).

Дополнительно есть экраны: календарь, дни рождения, важные даты, профиль/настройки.

## Что приложение не делает

- нет синхронизации между устройствами и облака;
- geo и ручной выбор местоположения для погоды пока не реализованы и остаются будущим расширением;
- история не подгружается из внешних «этот день в истории».

## Порядок восприятия главного экрана

Фактический порядок блоков в `index.html`:

1. Приветствие и дата  
2. Погода  
3. Праздники и даты  
4. Историческая справка  
5. Поздравления + Анекдот дня  
6. План на сегодня  

Нижняя навигация: Главная · Задачи · Календарь · Настройки.

На главной используется блок «Тихая мысль», который работает через `js/gentle-thought.js` и `assets/data/wisdom.json`.

## Ключевые модули

| Модуль | Суть |
|--------|------|
| History | History Core **завершён**: `history-events-ru.json` + `js/history.js`; база 366/366 дат с verified WORLD; RU — дополнительный редакционный слой (не требуется на каждой дате); одно показываемое событие дня; остальное — редакционная подборка в данных (Решение №009 / №010) |
| Weather | `js/weather.js`; текущая погода и прогноз на 5 дней через Open-Meteo |
| Holidays / calendar events | `calendar-events-ru.json`, `calendar-events-ru-movable.json`, `js/holidays-ru.js`, `js/orthodox-easter.js` |
| Tasks | `js/tasks-storage.js`, ключ `my-day-date-tasks-v1` |
| Birthdays | `js/birthdays-storage.js`, ключ `my-day-birthdays-v1` |
| Important dates | `js/important-dates-storage.js`, ключ `my-day-important-dates-v1` |
| Profile | `js/profile.js`, ключ `my-day-user-settings-v1` |
| Calendar | `calendar.html` + `js/calendar.js`; выбранная дата открывается через `index.html?date=...&cal=...` |

## Принципы продукта

Из `PROJECT_RULES.md` / паспорта:

- простота важнее количества функций;
- главный экран — про сегодняшний день;
- сначала мир вокруг человека, потом задачи;
- один этап = одна задача;
- не менять архитектуру без обсуждения.

## Источники данных (обзор)

- **Локальные JSON** в корне проекта: история, календарные события, мысли.
- **localStorage**: задачи, дни рождения, важные даты, настройки пользователя.
- **Внешний API погоды**: Open-Meteo (текущая погода и прогноз на 5 дней).
- Исторические изображения: `assets/history/`.

## Текущий статус проекта

- PWA-оболочка и главный экран работают локально (через `python -m http.server` / `Запустить Мой день.cmd`).
- Weather Core завершён: mock заменён на Open-Meteo; работают текущая погода и прогноз на 5 дней; geo и ручной выбор местоположения пока не реализованы и остаются будущим расширением.
- History Core **завершён**. UI заморожен (closed = изображение + название; open = дата + название + summary + fact при наличии + источник); пользователю показывается одно событие дня — первое после сортировки `editorialRank → interest → priority → year` (отсутствие `image` не меняет выбор; closed/open = одно событие; нет image-fallback); до трёх событий остаются редакционной подборкой в JSON (Решение №009); отсутствие image у главного — **backlog**, не блокер готовности модуля; критерии — в `docs/DESIGN_RULES.md` / `docs/EXAMPLE_DAY.md`.
- History Core закрыт: 366/366 дат с verified WORLD; помесячные RU-аудиты выполнены и не являются условием готовности модуля. Дальнейшее точечное улучшение данных, изображений и RU — необязательный backlog.
- Документы в `docs/` — актуальная рабочая документация.
- Корневые документы (`PROJECT_PASSPORT.md`, `PROJECT_RULES.md`, `DESIGN_PHILOSOPHY.md`, `ROADMAP.md`) пока исходные ориентиры.
