# Историческая справка v1.1

## Назначение

Короткая историческая история дня, которую интересно читать утром за 15–20 секунд.

Пользователю показывается **одно** главное событие дня. Остальные события даты в JSON — часть редакционной подборки и в текущем UI не показываются (Решение №009).

## Структура

### Закрытая карточка (вход)

- заголовок раздела «Историческая справка»;
- фотография;
- название события;
- без summary;
- без fact;
- без ссылки на источник.

### Открытая карточка

- без заголовка «Историческая справка»;
- дата в формате: `23 июля · 1962`;
- название события;
- полный summary;
- 💡 fact — **если есть** и усиливает событие;
- строка источника: `Источник` + `↗ …` (URL на экране не показывать).

## Правила текста

- простой русский язык;
- без энциклопедического стиля;
- одно событие = одна история;
- fact необязателен; если есть — понятен без дополнительных объяснений;
- текст читается за 15–20 секунд.

## Правила дизайна

- премиальный минимализм;
- иерархия через типографику и воздух;
- без лишних декоративных элементов;
- открытая карточка без заголовка раздела;
- фото-карточка остаётся входом в раздел.
- UI модуля History считается **замороженным**; изменения вёрстки и поведения — только отдельным решением.

## UX

После прочтения человек должен запомнить суть истории дня (и fact — если он был) и при желании перейти к источнику.

Переключение closed ↔ open: клик / Enter / Space; возврат в closed: Escape.
