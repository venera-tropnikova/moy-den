# Стандарт отбора мудрых мыслей

Мысль попадает в библиотеку только если одновременно выполняются все условия:

1. Подлинная, с проверяемым источником.
2. Автор и произведение известны (если применимо).
3. Понятна без пояснений.
4. Не является нравоучением.
5. Не является банальной или заезженной цитатой.
6. Вызывает внутренний отклик.
7. Подходит для спокойного утреннего чтения.
8. Хочется прочитать её ещё раз.

Если хотя бы один пункт не выполняется — мысль не включается.

Источник отбора:
- только первоисточники и академические переводы;
- не использовать сайты с подборками цитат как источник;
- при сомнении — не включать.
